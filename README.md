# Classic Sudoku Web App

브라우저에서 `index.html`을 열면 바로 플레이할 수 있는 클래식 스도쿠 웹앱입니다.

## 기능

- 9x9 클래식 스도쿠
- 쉬움, 보통, 어려움 난이도
- 쉬움 10분 안에 5개 완료 시 보통 잠금 해제
- 보통 30분 안에 4개 완료 시 어려움 잠금 해제
- 잠긴 난이도 버튼 비활성화
- 새 게임 생성
- 숫자 입력 및 지우기
- 행, 열, 3x3 영역 하이라이트
- 오답 표시
- 완료 판정
- 타이머와 실수 횟수
- 현재 게임, 선택 칸, 타이머, 실수, 잠금 해제 진행률 저장
- 중간에 나갔다가 다시 열면 이어하기
- 모바일 화면 대응

## 실행

`index.html` 파일을 브라우저로 열면 됩니다.
